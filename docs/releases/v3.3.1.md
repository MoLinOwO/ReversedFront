# ReversedFront 3.3.1

修正 Windows 安裝程式顯示「WebView2 setup failed」與 PowerShell 語法錯誤，導致安裝中止的問題。

- 已有 WebView2 時正常繼續安裝；缺少時仍會下載並驗證 Microsoft 官方引導安裝器。
- 保留 GPUI 桌面視窗、帳號管理、語言／音量設定及既有 Mod 功能。
- 發布前新增實際執行 Windows 安裝前置程序的檢查，涵蓋完整腳本執行與失敗時中止安裝。

3.3.0 的發布及下載附件已撤下。若安裝 3.3.0 時遇到錯誤，請關閉該安裝程式，改用本版安裝檔，沿用原安裝位置並保留 `accounts.db`。

Windows 提供 `.exe`／`.msi`；macOS 15 以上提供通用 `.dmg`；Linux x86_64 提供 `.AppImage`／`.deb`，需要 X11 或 XWayland。macOS／Linux 的完整遊玩流程仍待實機驗證。
