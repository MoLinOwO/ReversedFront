# ReversedFront 3.3.0

此版已撤下：Windows `.exe` 的 WebView2 前置檢查發生腳本截斷問題。請使用 [3.3.1](v3.3.1.md)。

本版將桌面視窗改為 GPUI，遊戲與 Mod 持續在同一個內嵌視窗中運行。

## 更新內容

- 更新桌面視窗架構與原生功能連接方式，應用程式名稱維持 ReversedFront。
- 沿用帳號自動登入、本機 SQLite 帳號庫、多視窗帳號隔離、語言及音量設定。
- 保留城鎮資訊、固定／隨機獎勵、工作站、勢力圖、飛機／港口航線、商城與 Discord 功能。
- Mod 採用新的桌面連接入口，並保留已發布舊版本的相容轉接。
- 更換獨立安裝包工具，移除舊 Tauri 執行期與專案設定。
- 發布內容會檢查私人帳號資料、設定、憑證及 Mod 原始碼，公開版本僅含已編譯 Mod 與公開素材。

## 更新方式

關閉其他 ReversedFront 視窗後，依桌面更新提示安裝，或下載符合系統的安裝檔並沿用原安裝位置。保留既有 `accounts.db`；更新不需要重新建立帳號資料。下載的更新檔位於系統「下載」資料夾。

## 平台與驗證

- Windows x64：提供 `.exe`、`.msi`。已在本機驗證登入、主大廳、城鎮地圖、Mod 載入及安裝包產出。
- macOS：提供通用 `.dmg`，需要 macOS 15 以上。
- Linux x86_64：提供 `.AppImage`、`.deb`，需要 X11 或 XWayland。

macOS／Linux 完整遊玩流程、兩個不同帳號同時登入及跨版本實際升級仍待實機驗證。GPUI WebView 整合目前屬上游實驗性功能；遇到問題請附上作業系統、版本與重現步驟，勿附帳密或帳號資料庫。
